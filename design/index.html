RuneShare: design directions

Four static mockups. Each file holds Home, Listing, Detail and Share pages with a sticky tab bar to jump between them, and a light/dark toggle in the site nav. The daisyUI v5 theme for each sits in a marked <style id="daisyui-theme"> block in the file's head, ready to paste into assets/css/app.css.

  • 01 · LedgerDense dark data site like TempleOSRS: charcoal panels, gold rules, condensed caps, a table listing. Dark by default.
  • 02 · Ember GuideEditorial guide feel like The RS Guide: warm near-black, cream serif headlines, bronze accents, Cinzel wordmark. Dark by default.
  • 03 · Parchment CodexMedieval manuscript: parchment vignette, double-rule borders, wax-seal kind badges, drop caps, typewriter strings. Light by default; dark is stone and candlelight.
  • 04 · Runestone ModernClean modern app with rune-blue and gold accents, rounded cards with one-click copy, and a dark code panel for the string. Light by default.

All four are mobile-first; try them at 375px wide. Fake content only, with no Jagex assets or branding.
