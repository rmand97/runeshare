# Security

If you find a security problem in RuneShare (for example a way to read someone's
email, act as another user, or get around moderation), please **don't open a public
issue**. Report it privately instead:

**[Report a vulnerability](https://github.com/rmand97/runeshare/security/advisories/new)**

Include what you found, how to reproduce it, and what someone could do with it.
You'll get a reply as soon as possible, and credit in the fix if you'd like.

Please don't test against other players' accounts or data, and don't run load or
denial-of-service tests against runeshare.dk.
